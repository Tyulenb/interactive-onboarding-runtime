# interactive-onboarding-runtime

# Описание выполненной части

Были реализованы бекенд-модули runtime и tracking, взаимодействующие с SDK. 
SDK применяется для показа онбординга и получает данные о сценариях из модуля runtime.

**Модуль runtime** на основе данных о пользователе, странице и принадлежности страницы к проекту выдает SDK доступные сценарии онбординга и их наполнение - последовательность подсказок.

**Модуль tracking** используется для отслеживания прохождения онбординга пользователем. На каждое прохождение сценария создается отдельная сессия, на каждый шаг сценария - событие, которое привязывается к текущей пользовательской сессии. Собранная информация впоследствии используется для аналитики и формирования статистики.

Кроме того, были реализованы **middleware**-функции для извлечения токенов из заголовков запросов и их проверки: 
- токен тестирования - для выдачи тестового сценария администратору;
- токен администратора - для проверки доступа к админпанели;
- токен проекта - для проверки, что страница, на основе которой подбирается сценарий онбординга, принадлежит проекту.

Были написаны **Dockerfile** для создания образа бекенда и **docker-compose.yaml** для развертывания базы данных и бекенда.

Описаны необходимые **отношения базы данных** в файлах миграций.
# Особенности реализации
1. Для взаимодействия с SDK использовался REST API;
2. Для написания слоя репозитория использовалась библиотека sqlc;
3. Связанные запросы к базе данных оборочивались в отдельные транзакции.
